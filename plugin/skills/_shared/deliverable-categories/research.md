# Research deliverable check

The flow for a `[research]` criterion. Shared rules — obtaining the artifact, verdicts, the report entry — live in the `deliverable-categories.md` index beside this folder, which opens this file.

**Verified by:** deliverable check.

## Artifact

A report or brief: committed at head, or produced by the repo's generation command.

## Probes

- Every question the criterion poses has an answer, cited by section.
- Every claim a criterion depends on cites a source.
- Every cited source resolves.
- No placeholders remain: `TODO`, `TBD`, `[citation needed]`, an empty section.
- A figure quoted in two places agrees.
- Every source falls inside any stated recency bound.

## Review

Read each cited source and confirm it says what the claim says.

A source that answers gone or not found is a `FAIL`: a dead citation is a defect in the deliverable.

## Inconclusive when

- A source is unreachable for a network reason.
